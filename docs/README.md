# Documentation Index

This directory contains detailed documentation for the Gene Regulatory Networks (GRN) shape homeostasis simulation project.

## Documentation Files

- **[web-interface.md](web-interface.md)** — Setup, features, and usage guide for the Streamlit web application.
- **[docker.md](docker.md)** — Container architecture, Docker Compose usage, and troubleshooting guide.
- **[thesis-summary.md](thesis-summary.md)** — Scientific background, mathematical model overview, and thesis objectives.
- **[history-log.md](history-log.md)** — Chronological development log from the original 2017 thesis implementation through modern containerization.

## Visual Examples

The `images/` subdirectory contains reference figures generated by `examples/generate_documentation_images.py`:

- **Cell System Example** (`images/cell_system_example.png`) — Displays cells in discrete states (empty, quiet, moving, dividing) alongside SGF and LGF concentration fields.
- **Network Example** (`images/network_example.png`) — Illustrates a directed gene regulatory network with feedback loops.
- **Evolution Example** (`images/evolution_example.png`) — Shows best and mean fitness progression across generations of the genetic algorithm.

To regenerate these figures locally:

```bash
python examples/generate_documentation_images.py
```

## Contributing to Documentation

When adding or updating documentation:

- Use lowercase filenames separated by hyphens (e.g., `model-parameters.md`).
- Keep formatting clean, concise, and free of decorative emojis.
- Update this index when introducing new documentation files.
